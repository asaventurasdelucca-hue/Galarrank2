GALARRANK v0.1.7 — NeoForge 1.21.1 / Cobblemon 1.8.3

PROJETO-FONTE, nao e o jar. Compile pelo Github Actions e baixe galarrank-jar.

CORRECOES:
- NPCs de GalarRank nao dao drops de Pokemon derrotados (Cobblemon LOOT_DROPPED e NeoForge LivingDropsEvent).
- Os Pokemon selvagens continuam dropando normalmente.
- Rotom Drone nao e mais um Rotom Pokemon: e um pequeno drone voxel com corpo vermelho, tela e helice lateral.
- K invoca o drone fisico, abre o painel; K de novo recolhe. Clique no drone reabre o painel.
- Radar/pontos/rank em GUI. Alertas curtos na action bar, sem poluir o chat.
- Remocao segura de NPC: /galar admin unbind = remove vinculo e preserva skin.
  /galar admin delete confirm = exclui o Easy NPC vinculado sob a mira ate 5 blocos.

COMO ORGANIZAR OS NPCS:
1) Tenha Easy NPC instalado (o modulo Core + Config UI do seu pack).
2) Crie manualmente NPC usando a ferramenta / editor do Easy NPC e escolha a skin.
3) Deixe o NPC em lugar seguro e parado. Fique ate 5 blocos e mire diretamente nele.
4) Execute /galar admin bind cadete (ou marcos, heitor, bruna, valentina, milo, nessa, kabu, bea, opal, melony, piers, raihan, leon, teste).
5) Clique direito para batalhar. Depois pressione K para achar treinadores perto.
6) Para alterar o treinador: mire e /galar admin bind <outro_id>.
7) Para manter o NPC, mas tirar batalha: /galar admin unbind.
8) Para excluir o NPC de verdade: /galar admin delete confirm, mirando nele. Nao tem desfazer.
9) /galar admin spawn <id> e /galar admin setup necessitam presets Easy NPC WORLD galar_<id>; NPCs manuais com bind NAO precisam de presets.
