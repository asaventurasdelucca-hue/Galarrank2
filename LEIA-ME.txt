COMO SUBIR NO GITHUB
- Envie a estrutura COMPLETA do projeto, incluindo src/, build.gradle,
  settings.gradle, gradle.properties e .github/workflows/main.yml.
- Remova workflows antigos .github/workflows/build.yml (se houver), para
  evitar duas builds desnecessarias.
- Na aba Actions do GitHub, execute Build GalarRank.
- Se verde: baixe galarrank-jar, EXTRAIA o ZIP e use o .jar dentro de mods/.
- Se vermelho: baixe build-log, envie o arquivo build.log para diagnostico.
